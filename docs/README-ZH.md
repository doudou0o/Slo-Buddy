# Slo-Buddy

运行在本机的飞书 AI 伙伴服务，通过 Codex SDK 处理对话，并提供独立的人设、记忆、受控工具和定时任务。

```text
飞书用户 / 群聊 / 话题
          ↕ 消息与卡片事件
Slo-Buddy service（本机常驻）
    ├─ 配置中心 / 权限 / 排队 / 定时任务
    ├─ 本地记忆 / 背景知识 / 会话状态
    └─ Codex SDK ↔ 模型与受控 MCP 工具
```

## 公开源码中的默认设置

人设为空，不继承安装者的全局人设。飞书接入与浏览器默认关闭，定时任务模板全部暂停。仓库不包含原安装者的背景知识、成员ID、凭证、聊天记录、长期记忆、图片或运行日志。美团Skill独立携带，仅支持尝试选餐加购，不提交订单或付款；网站风控可能导致不可用。

启用定时任务前，填写自己的应用、群、城市坐标与文档ID，先测试再逐项启用。每日天气、工作日闲聊和群日记模板均使用Asia/Shanghai；可按需要调整。

## 快速开始

当前版本在 macOS + Node.js 22 上验证，使用包内锁定的 Codex CLI / SDK。接收者需使用自己的 Codex 登录和飞书应用凭证。

```sh
npm ci
npm run setup
./node_modules/.bin/codex -c cli_auth_credentials_store='"file"' login
```

在本机填写 `.private/apps/main.env`，然后启动：

```sh
npm start
```

打开 [本机配置中心](http://127.0.0.1:18343/)，在「飞书接入」连接应用并按提示私聊配对。首次初始化的应用处于未连接状态，文件、文档和画图能力默认关闭，按需要分别开启。完整飞书权限和事件设置见[搭建指南](SETUP.md)。

## 开发与分发

```sh
npm test
npm run package
```

`package` 从最新 Git commit 生成 `artifacts/releases/` 下的源码压缩包及 SHA-256 校验文件。必须先提交，且工作区无未提交文件。脚本检查发布路径和疑似凭证，不打包 `.git`、本机配置、数据库、聊天记录、认证、日志和附件。

请分享生成的发布包，**不要直接压缩已经运行过的整个项目文件夹**。该版本是源码分发包，不是双击安装的独立桌面应用。

## 主动相处

配置中心导航末尾新增「主动相处」。内置 Default Harness，支持线索采集、话题接续、试运行、来源查看和历史线索导入；默认关闭，开启前选择会话范围。详见 [功能说明](COMPANIONSHIP.md)。
