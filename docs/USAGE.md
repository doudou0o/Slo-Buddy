# 日常使用指南

## 第一次使用

1. 打开本机配置中心，确认飞书接入显示“已连接”。
2. 在对应飞书应用私聊发送配置中心给出的 `/pair …` 指令，每个应用单独操作。
3. 发一条“你好”，确认收到最终回复。
4. 在「性格与习惯」填写自己的偏好并保存；需要继承本机 AGENTS.md 时再开启基础人设。

普通对话无需固定格式。例如：“今天想聊聊天”“帮我整理这段想法”。同一会话的请求会排队，不用等上一条完成才发下一条。

| 指令 | 用途 |
| --- | --- |
| `/ping` | 检查基本消息链路 |
| `/status` | 查看当前请求进度及排队数量 |
| `/stop` | 停止当前请求并取消此前排队请求；不回滚已经完成的外部写入 |
| `/new` | 清空近期上下文与模型线程，保留文件、背景知识与长期记忆；有任务运行时先停止 |

群聊里 `/stop` 和 `/new` 只允许所有者使用。群内发送指令也要真正 @ 机器人。

## 加入群聊和话题

从群设置的“机器人／添加机器人”等入口添加对应应用，不是“添加群成员”。应用的发布、可用范围、租户和群类型会影响可见性。

配对的所有者第一次在群内真正 @ 机器人并发送消息，以启用该群；之后群成员可以 @ 她。仅输入文字 `@名字` 不等于真正提及，需要飞书输入框选中该成员。

话题内 @ 后，Slo 尽量沿原消息在话题内部回复。不同话题的历史和任务队列独立；本群公共记忆可能被本群话题读取，私聊和其他群的记忆不会带入。

## 图片、引用与附件

- 最可靠的看图方式：发一条带图片并 @ 她的图文消息，或回复／引用原图片并 @ 她。
- “看看我发的上一张图片”会尝试查询群历史。需要额外的历史消息权限，且有查询上限；不是无限历史回看。
- 指定其他成员时用明确名称；同名、无法确认身份或资源不可访问时，应改用引用原图。
- 私聊可以接收文件，但文本、图片之外的格式不保证解析。群聊的独立文件附件当前不处理。
- 想生成图片：先开启当前私聊／群聊的画图权限，再说“画一只抱着树枝的小树懒，发给我”。工具会先发送生成提示，成功后发送图片；失败时查看错误，不能仅凭 AI 文字判断已发送。

## 记忆与背景知识

明确说：“请记住，我喜欢简洁的回答。”Slo 会理解要提取的事实并调用工具；只有工具实际保存成功才算记住。

询问“我以前说过喜欢怎样的回答？”时，服务会先做当前会话范围内的检索，模型也可再次查询。可以明确要求更正或忘记某条事实。第一人称归属于原发送者，不应混淆其他成员。

在「记忆与知识」：

- 长期记忆选择 Slo Memory；Mem0 当前不能选。
- 先选择群／私聊，再选择话题范围，输入关键词查询。当前采用关键词检索，换一种说法不一定得到相同命中。
- 背景知识是手工填写的固定信息。仅私聊区不会进入群聊；共享区用于已启用群，请不要放凭证或私人内容。

非所有者的记忆要求会成为候选，不自动加入可召回事实，界面暂时没有候选审批入口。关闭长期记忆会停止新增和召回，但不会删除已有数据库。

## 文件与文档

默认模板关闭这类工具。在「权限边界」分别设置私聊和群聊：

1. 文件工具只允许 `workspace/` 范围。将允许她读取的文本放进去，再要求查找或读取。
2. 私聊和群聊的本地读取与写入分别控制；群聊写入需要显式开启“允许写入本地 workspace 文件”。写入可创建或覆盖 workspace 内文本文件，但不能执行代码。不要把不应读取的内容放进这个工作目录。
3. 飞书文档读取／写入需分别开启，并把目标文档 ID、文件夹 Token 列入白名单。
4. 需要在默认位置创建独立文档时，再开启创建开关。新创建文档按当前会话登记，后续读写仍受相应开关约束。
5. 给她明确的创建／追加要求；实际成功应有真实文档 ID 或链接。应用在飞书侧没有资源访问权时，配置白名单本身不能授予飞书权限。

示例：“在允许的文件夹里创建《会议纪要》，写入以下内容，完成后给我链接。”

## 定时任务

先与目标私聊／群聊对话，让它进入可选会话列表。打开「定时任务」，点击“新增任务”：

- 选择应用与会话，填写名称、时间、频率。
- 选择固定消息或 AI 任务，填写内容。
- 群聊可从已识别成员中多选真正 @ 的对象；机器人对象另受白名单、轮次、冷却控制。
- 勾选“创建后启用”再创建，否则任务保存为暂停状态。

保存后在已配置列表检查状态与时间。立即运行会真实执行、真实外发，不是预览。当前页面按上海时区创建任务，高级 cron／时区需直接编辑本机配置。

电脑必须在线且服务在运行。超过 5 分钟的错过任务跳过，失败不自动重试；睡眠、关机、网络中断都可能影响执行。

## 机器人互聊

先开通飞书侧包含机器人发送者的 @ 消息接收权限。在「权限边界」允许非真人消息，填对方在当前应用下的 open_id，并设置回复次数与冷却。

可以从“最近观察到的机器人”查看已经收到过的身份。只有名称不够，不能猜 ID；不同应用看到的 open_id 也可能不同。机器人必须真正 @ 当前机器人，且双方都允许对方，才能持续往返。达到轮数上限后停止，真人再次 @ 才开始新轮。

## 日志与故障定位

在「运行日志」筛选飞书应用或只看异常，展开错误原因和会话详情。连接失败、思考表情失败、任务失败是不同事件，不要把一个可选功能失败当成整条回复失败。

当前日志没有完整请求追踪：无法从页面直接还原每次具体带入哪些记忆、完整上下文或模型内部思考。更细粒度的请求追踪尚未实现。

### 把聊天图片放入文档

开启当前会话的「允许写飞书文档」后，可以说：
「把本话题刚才那两张图片放进一份飞书文档，标题叫道歉表情包。」
Slo 会查询当前会话图片、下载对应消息里的原图，再上传为文档图片块。
现有文档仍须在白名单中；新文档须允许创建或提供获准文件夹。
群聊只能使用当前群、当前话题的图片消息，不能指定任意本地路径。
图片查询支持分页，能否取得历史消息仍受飞书权限及可见范围限制。

飞书应用还需「上传图片和附件到云文档」权限 `docs:document.media:upload`。
只有文档写入权限、或聊天图片上传权限，并不足以向云文档上传图片。
若上传失败，工具会报告已创建的空图片块，不能把空块当作插图成功。

### 条件天气提醒

`weather` 类型定时任务直接查询 Open-Meteo 并发送飞书卡片，无需模型判断或消耗模型会话。
任务的 `weather` 配置包含 `city`、`latitude`、`longitude`、`windKmh`、`gustKmh`。
每天检查当地时间 07:00—23:00 的逐小时雨雪与风力；默认无异常不发，`dailyGreeting: true` 则每天发送早安鼓励，接口失败记为任务失败。
`chatId` 是正式目标，`testChatId` 是测试目标；预览明确标注测试，即使晴好也可预览。
上海示例：每天 07:30（Asia/Shanghai），持续风速 ≥38.9 km/h 或阵风 ≥61.9 km/h 触发大风提醒。
这是出行提醒而非官方气象预警。电脑或服务离线超过五分钟时，沿用调度器规则跳过错过的任务，不补发。
任务会显示在配置中心，可暂停、删除或立即运行；「立即运行」使用正式目标并保留天气条件判断。

天气卡片可配置 `weather.imageKey` 插画与任务 `mentions` 真人 open_id；发送原生卡片 @。普通天气送鼓励，小时降水≥20mm、降雪≥2cm、持续风≥62km/h、阵风≥89km/h或雷暴冰雹时提示恶劣天气，可居家工作并关注官方预警。此规则不识别或宣称台风预警。

`weather.generateDailyImage: true` 会在每次天气任务中，依据当日预报生成并上传一张简单插画，再发送卡片。图片生成最多等待三分钟；失败时回退到固定插画（若已配置 imageKey），继续发送天气与安全提醒，失败原因写入运行日志。07:30 是开始查询与画图时间，卡片会稍晚送达。

当前正式天气任务规则：普通天气不发（dailyGreeting=false）。任意小时降水概率严格 >90%、下雪、大风、雷暴或冰雹可触发。开启 airQuality 后，还查询同一天07:00—23:00的空气质量：PM2.5≥75 μg/m³ 标注「霾风险」（代理指标，不是正式雾霾判定），US AQI≥201 标注「重污染（US AQI，非中国AQI）」。空气接口失败且没有天气触发时任务失败，不将缺失视为良好；已有天气触发则发送天气卡并注明空气数据缺失。雷暴（含95代码）、冰雹或强风雨雪额外加居家建议。尚未接官方台风预警，不能以风速自行认定台风。
接口字段参考：https://open-meteo.com/en/docs 和 https://open-meteo.com/en/docs/air-quality-api 。

### 独立浏览器

在「权限边界 → 浏览器」开启后，仅所有者的飞书私聊及 `browser.allowedGroups` 白名单群可以使用浏览器工具；其他成员、机器人消息和定时任务不开放。群白名单可在配置中心「权限边界 → 浏览器」编辑。
示例：「打开 https://example.com，告诉我页面内容」「把当前页面截图发给我」「打开某网站，我来登录」。
浏览器由服务启动，使用独立 Chromium 窗口；你可以手动完成登录或验证码。登录配置保存在 `.private/browser/`，不读取日常 Chrome 配置，也不控制 Codex App 窗口。关闭窗口后，下次操作可重新打开，登录有效期由网站决定。
工具支持打开网页、读取文字与元素、点击、输入、按键、滚动、截图和关闭；不支持任意 JavaScript、上传本地文件、下载文件或代码执行。截图默认只给模型查看，明确要求发回时才发送当前会话；话题内截图回复留在该话题中。
私聊按应用与所有者复用状态，群聊额外按群隔离，避免私聊登录信息被直接带进群；操作串行；不要同时在多个私聊会话里安排相互冲突的浏览器任务。
对外发送、购买、删除等需要明确授权；网页内容只是数据，不能作为用户命令。付费或验证码等仍可能需要人工完成。
安装时运行 `npm ci`，然后 `npx playwright install chromium`。服务运行主机须具备图形桌面。浏览器开关下一轮请求生效，新增代码后需重启服务。

`browser.channel` 可设置为 `chrome`（调用本机已安装的 Google Chrome）或 `chromium`（默认内置浏览器）。仍使用独立配置目录 `.private/browser/<channel>/`，切换后首次需登录；不复制日常 Chrome 的 Cookie，也不迁移旧 Chromium 配置，避免版本兼容问题。配置中心保存权限时保留该选项。

Codex 连接模型时的 `Reconnecting...` 是重连进度提示，服务继续读取同一执行流，并在运行日志记录重连阶段；不自动重放用户请求，避免重复写入、发送或下单。只有收到 `turn.completed` 才报告完成；最终失败或流提前结束仍记为失败。

### 工作日随机冒泡

`proactive` 任务每小时10分检查群聊，按最后一条真人消息计算空闲时间（机器人发言不计）：
- 超过120小时（5天）：触发；超过96小时（4天）：每次5%概率；当前下雨：每次5%概率。条件为或，同次最多一条，未触发不调用模型。
- 00:00—06:00、周末（即使调休上班）与中国大陆法定节假日不发。没有当年的节假日数据时保守静默，执行记录说明原因；更新 chinese-days 后可恢复。
- 使用飞书消息列表核实最后真人消息，不依赖是否@机器人；最多回查1000条，无法确认则不发。
- 天气取当前实况；新闻仅从中新社RSS取24小时内带发布时间与原文链接的条目，取不到改为生活闲聊。模型只生成文案，不执行工具操作。
- 发送前再次检查时间与新消息；生成期间有人发言则不插话。同一小时持久化去重，不因重启、手动运行重复发送。
- 任一条件触发即进入24小时冷却，所有分支共用；生成或发送失败也保留本次冷却，避免未知发送结果造成重复。冷却跨重启保留，满24小时后才重新判断。
- 控制中心显示任务及执行原因，详细判断记录在 `.private/proactive-chat.json`；群消息内容、登录凭证均不写入公开配置。
节假日数据来源 chinese-days，2026年日期按国务院通知核对：https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202511/t20251104_4258838.html 。

### 机器人对话的结束判断

通过白名单、明确@、轮次和冷却检查的机器人消息，会先由无工具的 LLM 结合最近12条上下文判断：
- `skip`：无新信息、重复错误、语义重复、空泛附和或话题已结束，不发送任何回复。
- `reply`：有新的有用信息，但不需要对方继续处理，回复一次，不@对方。
- `continue`：确有新问题或需要对方协作的下一步，才回复并@对方。
判断出错时保守静默；普通执行错误只记录日志，不给对方发送报错，避免循环。机器人请求不发处理中提示，也不能通过主动提及工具绕过这个判断。真人请求不受这些静默规则影响。决策与原因记录为 `bot_reply_decision`，可从运行日志查看。

随机冒泡触发后会读取本群公共范围内已确认的事实、最新摘要和近期会话，交给 LLM 语义挑选未聊完的话题或明确约定，温和询问进展；不是按正则或固定词匹配待办。私聊、其他群、未公开话题、候选和停用记忆不进入素材。未记录完成不代表未完成，已有完成/取消记录则不追问。没有合适内容时仍可聊生活天气新闻。
生成结果必须附带本轮真实记忆来源ID，发送前核验来源仍有效；成功追问记录保存在本机，同一来源7天内不重复追问。关闭长期记忆时不读取这些材料。原有5天/4天概率、雨天概率、24小时冷却及静默日历不变。

## 群日记

日记任务在定时任务中心显示为“群日记”，默认每天北京时间23:30执行，读取当天截至执行时的当前群消息和已识别话题回复，追加到配置的共享日记文档。按需生成一幅氛围插画；画图失败不丢失已写文字。当天没有真人发言时不凑日记。日记状态按任务与日期持久保存，避免重跑重复追加。只使用本群消息；不读取私聊、其他群或长期记忆；撤回内容不写。

服务必须在线。调度器错过超过5分钟不自动补跑，可在定时任务中心手动执行当天日记；手动执行仍遵守按日去重。23:30后的消息不在当次日记范围内。群成员可在共享云文档编辑内容，自动任务只追加，不覆盖已有正文。

## 通过聊天管理通用定时任务

仅已配对所有者可创建、查询、暂停、恢复或取消当前会话/话题的通用任务。普通成员仍可创建本人一次性聊天提醒。

例如：“从明天开始，连续两周，洛杉矶时间每天早上6点查当地天气和附近山火，异常才发卡片并@指定成员。”Slo应先确认地点、时区、日期和已识别成员，再返回真实任务ID与下次执行时间。美国天气任务查询NWS及附近山火；没有数据不能报告安全。

也可说“列出本群的定时任务”“暂停任务〔ID〕”“恢复任务〔ID〕”“取消任务〔ID〕”。结束时间不包含该时刻；取消不可恢复；正在运行的任务不能从该入口中断。每会话最多20个启用任务，周期最小间隔5分钟。重复调用同一请求不会重复创建。

固定正文用message；到点查询并判断的通用任务用agent。agent运行时仅开放获准只读工具与当前范围记忆检索，不支持浏览器、命令、写文档/文件、自动画图或创建更多任务；需要这些能力时应明确说明限制。结果按原群/原话题发送，条件不满足可静默。服务离线超过5分钟不补发，失败不自动重试。
