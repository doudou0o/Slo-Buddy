# 主动相处 · Default Harness

「主动相处」是 Slo Buddy 内置的独立功能模块。页面展示固定的 Default Harness，当前不可选择、替换或编辑实现；可以配置行为参数与两段 Prompt。未来可扩展插件化，本期没有插件注册或加载器。

## 第一版范围

实现“小事有后续”和“相处形成熟悉感”。生活话题可以在经历进行中接续，例如 某位朋友 出差时聊见闻；背景类线索保存有来源的旧梗、明确喜好和玩笑边界，仅影响表达，不单独触发联系。真实来源主动分享和附近生活小提议仍在 TODO，未在本期实现。

独立使用 `.private/companionship.sqlite`，不依赖长期记忆开关，不向长期事实记忆写入。复用现有调度器、模型调用、会话队列和飞书通道，没有新增依赖或独立进程。

## 配置和启用

配置中心 → 主动相处：

1. 选择已有授权的应用与会话，群主聊天和每个话题独立选择。
2. 开启模块与“允许保留日常相处线索”。这会处理所选范围内新的真人文字和图文中的文字，包括未 @ Slo 的群消息；不回填历史，不读取图片内容，不将其他机器人的发言作为来源。
3. 先保留“试运行”。候选只记在本地，不发送，也不占实际联系额度；仍会保留线索并调用模型。
4. 在“话题线索与主动记录”查看来源原文、时间依据、候选内容及简要选择理由。确认合适后，可关闭试运行进入真实联系。

新模块默认关闭、线索采集默认关闭、会话范围为空、试运行默认开启。原有定时任务不会被修改或删除。沿用配置中的对话模型和推理强度。

明确要求补入历史时，可通过配置中心同源鉴权的 `/api/companionship-import` 接口导入已筛选的线索。服务重新读取飞书原消息，检查真人来源、会话/话题和保留期限后原子写入；不修改采集或发送设置、不调用选题发送。生活话题必须设置未来的接续时间。重复导入会去重，已删除来源不能通过回填恢复；未参与回填的新消息仍保持待处理。

默认节奏：

| 配置 | 默认值 |
| --- | --- |
| 停聊后提取 | 2 分钟 |
| 持续聊天最长合并间隔 | 10 分钟 |
| 主动检查间隔 | 30 分钟 |
| 联系窗口 | 北京时间 09:00 至 22:00，不含结束时刻 |
| 周末 | 允许；这一模式不额外排除节假日 |
| 聊完至少等待 | 30 分钟，包含 Slo 完成回复后的等待 |
| 联系间隔 | 滚动 24 小时至少间隔一次，可配置得更长 |
| 数据保留上限 | 30 天；线索可有更短有效期 |

复用调度器每分钟的内部检查，因此提取时刻可能比阈值晚约一分钟；队列繁忙或机器离线时还会延后。没有新对话不提取，没有合适候选不调用选题模型。恢复在线后按当前信息重新判断，不补发历史时段的消息。

## 数据与执行

- `conversation_events`：带来源消息 ID、人物、文字、时间的有限期近期上下文，以及正常聊天的回复。
- `clues`：生活话题或相处背景，来源、所属会话与人物、时间依据、接续窗口、过期时间和状态。
- `decisions`：发送、暂缓、静默、试运行候选和处理失败记录。
- `scope_state` / `conversation_activity`：会话版本、检查与失败重试时间、最近回复时间。
- `contact_ledger`：新模块与旧冒泡共用的发送额度；同一应用与群/私聊的所有话题共享。
- `observed_sources`：有限期的消息去重标识，避免删除后重放旧事件重新生成线索。

模型以无工具调用返回结构化数据。提取按消息增量合并处理，输入有大小限制；已有线索优先更新。选题先用程序过滤范围、状态、时间和频率，再交给模型选择最多一个话题，或返回暂缓、静默。

发送前重新检查授权、配置、会话版本、忙碌状态、有效期和共享额度。新消息、删除或设置变化会取消生成中的候选。发送前持久化预约；异常或缺少回执时标为结果待核实，消耗本次额度，不自动重发。重启也不会重发不确定消息。

消息发出后线索进入等待回应状态，未回复不换问题继续催。来源人物后续的新相关发言可以由模型关联并重新打开话题；其他人的发言不能把等待状态重新打开。背景线索会通过当前会话上下文传给正常聊天模型，保持与长期记忆独立。

## 群聊接续与边界

普通未 @ 的群消息只观察，不自动插话。来源人物直接回复一条已发出的主动消息时，可不额外 @，仍按原话题关联线索；普通群聊天继续遵守原 @ 规则。线程回复沿用现有飞书回复通道。未主动 @ 成员，未开放机器人互相触发。

只有当前范围的线索进入提示词。程序会核对来源、所属人物与时间格式，但对语义和时机的自然程度仍依赖模型，需通过试运行观察。首版不做向量检索、情绪画像或亲密度评分。

停止跟进会保留线索并禁止主动追问。删除会清空该线索内容，并为避免原文或候选让它再次出现，清除本模块该会话的近期原文及候选正文；其他线索保留。不会删除飞书原消息，也不会清除原有聊天历史或长期记忆。

## 验证边界

自动化测试覆盖合并时机、来源与会话隔离、持续中的出差话题、回复关联、取消/删除/过期、周末与时间窗口、试运行、共享额度、并发与重启、不确定发送。配置页可在隔离环境中验证保存和布局。

真实模型验证可以使用合成对话，并强制试运行，避免发往实际会话。飞书未 @ 消息能否送达、真实线程回复及长期相处质量，仍需在选定会话启用后做端到端观察，不能用本地测试结果替代。
